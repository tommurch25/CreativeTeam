Setting up a proof

Three things on every one

Every proof is set up the same way.

01
Everyone on it
  • Creative gatekeepers, and Joe on copy
  • All six of performance marketing
  • Nobody added late, nobody left out
02
A sign-off date
  • The date the proof needs to be back by
  • Set when the proof is created
  • Shows as the due date for every reviewer
03
Motion in a collection
  • Every cut and size of a concept together
  • Reviewed side by side
  • One sign-off date for the whole set
Miss oneand the proof stalls: someone can’t see it, nobody knows when it’s due, or a cut gets signed off on its own.

Make sure everyone is on it.
